Kamuflaže: šumska, pustinjska, urbana, tropska, snežna i premium; svaka ima šest paleta i šest dezena. Premium palete: Zlatni pepeo, Krvavi mesec, Kobalt, Ametist, Patina i Obsidijan. Teksture nisu seamless; spojeve treba doraditi za kontinuirane UV površine.

## Prethodne verzije

Ranije generisani `ewarstate/helmets`, `ewarstate/headgear50`, `ewarstate/expansion` i koncept table ostaju kao istorijski materijali. **Za novu opremu koristi `assets v2/`**; ranije serije zamenjene su kompletnom ponovnom izradom. Izvori i skripte nove kolekcije su u `ewarstate/v2/`.
