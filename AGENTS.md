# eWarState asset instructions

Follow ASSET_NAMING.md for every new equipment asset and ID: type_model_color, e.g. helmet_1_3.png, uniform_1_1.png, vest_1_1.png. Model numbers identify distinct base designs within a type. Color/texture numbers start at 1 independently for each model. Keep assigned numbers stable; store palette/category/pattern descriptions in manifest metadata. Use unpadded integers consistently. Preserve original user-supplied source-pack names and concept-sheet names.
